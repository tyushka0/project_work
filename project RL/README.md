# Gym Data Analysis

Проект для анализа данных тренировок в тренажерном зале.

## Описание

Проект анализирует:
- длительность тренировок
- количество сожжённых калорий
- сон
- потребление белка
- изменение веса
- прогресс силовых показателей
- настроение и уровень энергии

Данные загружаются из CSV-файла и анализируются с помощью pandas и numpy.
